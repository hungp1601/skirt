Cần mở qua HTTP cục bộ để tải ES Modules

Chrome chặn import module khi mở trực tiếp bằng file://. Hãy nhấn đúp file start.command hoặc chạy lệnh sau trong thư mục game: 

python3 -m http.server 8765

Sau đó mở http://localhost:8765
